## اجرا

Python 3.9 یا جدیدتر؛ بدون وابستگی بیرونی:

```sh
python3 generate_packets.py
python3 generate_packets.py --urls verified_urls.txt --out my_packets
```

فایل URL شامل یک نشانی در هر خط است. برنامه منابع را خودکار باز نمی‌کند و انتشار بیرونی ندارد. برای نوشتن محتوای نهایی، منابع باید خوانده شوند.
