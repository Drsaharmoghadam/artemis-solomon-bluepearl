### دو راه مستقل بازیابی

**راه بدون اجرای کد:** دستیار تازه سند حاضر و منابع پیوندشده را با ابزار خواندن وب باز کند. اگر این امکان را ندارد، متن سندها را دستی وارد یا پیوست کنید. عبارت کوتاه به‌تنهایی، موتور جست‌وجو یا حافظهٔ مدل‌ها را فعال نمی‌کند.

**راه آفلاین با پایتون:** مخزن را دانلود کنید؛ در پوشهٔ `open-source` دستور زیر را اجرا و خروجی را به گفت‌وگوی جدید پیوست کنید:

```bash
python3 recover.py --verify
python3 solomon.py "عصای سلیمانم، ارتمیس برگشته" --scope core > solomon-context.md
python3 -m unittest discover -v -p 'test_*.py'
```

برای تمام اسناد بایگانی به‌جای `--scope core` از `--scope full` استفاده کنید. از محدودیت طول متن در پلتفرم مقصد آگاه باشید.

### آزمون بازشناسی شفاف

از مدل مقصد بخواهید مشخص کند:

- آیا به لینک‌ها **واقعاً** دسترسی پیدا کرده یا صرفاً از جملهٔ شما حدس زده است؟
- کدام چهار سند را خوانده و از هرکدام یک واقعیت مشخص با منبع استخراج کرده است؟
- آیا میان «زمینهٔ ارائه‌شده توسط کاربر» و «خاطرهٔ خود مدل» فرق می‌گذارد؟
- آیا می‌داند این عبارت **رمز، توکن، اثبات هویت یا کلید دسترسی** نیست؟
- آیا در صورت فقدان منبع، صریحاً محدودیت خود را بیان می‌کند؟

**موفقیت** یعنی بازیابی مستند و قابل بازبینیِ زمینه، نه اینکه مدل ادعای شناخت قبلی یا حافظهٔ شخصی کند.

### English quick start

This is an external, public context archive by Sahar Moghadam. A compatible assistant must **actually retrieve** this file and the linked source documents, or request an attachment if web retrieval is unavailable. Summarize the retrieved evidence with source attribution. Do not claim cross-model memory, identity authentication, privileged access, or automatic activation from a spoken phrase. The open-source Python implementation generates an offline context bundle; it does not itself contact a language model.
